# voice_flow
# 🎙️ Voice Flow

**Voice Flow** เป็นระบบเว็บแอปพลิเคชันอัจฉริยะ (Full-Stack AI Audio Processing System) ที่พัฒนาขึ้นเพื่อตอบโจทย์การจัดการเสียงพูดแบบครบวงจร ตั้งแต่การบันทึกเสียง, การอัปโหลดไฟล์เสียง, การถอดข้อความ (Transcript), การแยกแยะประเภทเนื้อหา, การสรุปประเด็นสำคัญ, ระบบถาม-ตอบเชิงลึกจากเนื้อหา (AI Q&A), ไปจนถึงการสร้างและดาวน์โหลดเอกสารรายงานสรุปผลอัตโนมัติ

---

## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

1. **Audio Input Management:**
   * รองรับการอัปโหลดไฟล์เสียงทุกรูปแบบ (`.mp3`, `.wav`, `.m4a`, `.ogg` ฯลฯ)
   * รองรับการกดบันทึกเสียงสดผ่านไมโครโฟนหน้าเว็บไซต์ (Live Recording)
2. **AI Analysis & Classification:**
   * แยกแยะประเภทและหมวดหมู่ของเสียงอัตโนมัติ (เช่น การประชุม, บรรยาย, สัมภาษณ์)
   * แปลงเสียงพูดเป็นข้อความถอดเสียง (Transcript)
3. **Smart Summarization:**
   * สรุปสาระสำคัญของเสียงออกมาเป็นข้อๆ ที่เข้าใจง่ายและกระชับ
4. **Interactive Q&A:**
   * ช่องถาม-ตอบอัจฉริยะที่สามารถพิมพ์ซักถามรายละเอียดเพิ่มเติมจากเนื้อหาเสียงที่บันทึกไว้ได้ทันที
5. **Document Export & Download:**
   * แปลงข้อมูลสรุปและข้อความทั้งหมดให้ออกมาเป็นไฟล์เอกสารรายงาน (.txt / .md) พร้อมดาวน์โหลดใช้งานได้ทันที

---

## 🛠️ สถาปัตยกรรมและเทคโนโลยี (Tech Stack)

* **Backend:** Python (FastAPI) - จัดการ API, ระบบประมวลผลไฟล์เสียง และการสร้างไฟล์เอกสาร
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript - ส่วนติดต่อผู้ใช้งานที่สวยงาม ทันสมัย และใช้งานง่าย
* **Server / Deployment:** Uvicorn, Render / Cloud Ready
